# README Atelier

**A little studio for your GitHub identity.** Build a profile README that feels like you, preview it as you edit, and export your own animated banner.

[Open the live studio](https://mhussain-codes.github.io/readme-atelier/) · [Explore the source](https://github.com/mhussain-codes/readme-atelier)

## Make your profile yours

- Add your name, GitHub handle, role, short introduction, location, and website.
- Feature two projects with useful one-line descriptions.
- Choose one of four original color moods.
- See a live profile preview and switch to the generated Markdown whenever you like.
- Copy or download README.md, then download the matching animated SVG banner.
- Remix the colors and sample project ideas with one click.

Your details stay in your browser. The studio does not ask you to sign in or send your profile data anywhere.

## Quick start

1. Open the [README Atelier studio](https://mhussain-codes.github.io/readme-atelier/).
2. Replace the sample information with your own. Use links and descriptions you are happy to share publicly.
3. Copy or download README.md.
4. Download the animated banner as profile-banner.svg.
5. In the repository named exactly like your GitHub username, add the banner at assets/profile-banner.svg. Create the assets folder if needed.
6. Add the generated README.md at the root of that profile repository.
7. Commit the files. Your GitHub profile will display the new README and banner.

The generated Markdown points to ./assets/profile-banner.svg. Keep that path, or change the image link if you choose another location.

## Built with

Vanilla HTML, CSS, JavaScript, inline SVG animation, and the Canvas-free browser platform. No framework, backend, account, tracker, or build step is required.

## Run it locally

Download or clone this repository, then open index.html in a modern browser. GitHub Pages serves the same file directly from the main branch.

## Accessibility and privacy

- Respects reduced-motion preferences.
- Includes keyboard-friendly native inputs and buttons.
- Escapes profile text before rendering it in the preview and accepts only safe web links.
- Keeps all profile editing in the browser; copy and file export happen only when you choose them.

Ideas and improvements are welcome. Open an issue to suggest a feature, or send a pull request with a focused change. Please keep the studio simple to host and free of tracking.
